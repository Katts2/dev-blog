## 프로젝트를 시작한 이유

게임 길드나 그룹에서 사용할 수 있는 시스템을 직접 만들어보기로 했습니다.

개발 순서는 다음과 같습니다.

```text
보스타이머
   ↓ 완료 후
아이템 경매
   ↓ 완료 후
정산 시스템
```

중요한 원칙은 **앞 단계가 완성되기 전에는 다음 핵심 기능으로 넘어가지 않는 것**입니다.

## 현재 개발 수준

저는 개발 초보자입니다.

그래서 단순히 완성된 코드를 복사하는 것보다 다음 내용을 함께 기록하려고 합니다.

- 무엇을 설치했는지
- 명령어가 무엇을 의미하는지
- 어떤 문제가 생겼는지
- 왜 문제가 생겼는지
- 어떻게 해결했는지
- 실제 운영할 때 무엇을 조심해야 하는지

## 사용할 인프라

기본 목표는 가능한 한 Always Free / Free Tier를 사용하는 것입니다.

현재 활용할 수 있는 자원은 다음과 같습니다.

- Cloudflare 도메인 및 무료 플랜
- OCI AMD Compute 2대
- OCI DB 2개
- GCP Compute Instance 1대
- Supabase
- Firebase
- MongoDB
- Neon
- AWS Free Tier
- Azure Free Tier

무료 자원이 많더라도 처음부터 모두 연결하지는 않습니다.

각 서비스가 실제로 필요한 시점에 역할을 정해서 하나씩 추가할 예정입니다.

## 첫 번째 목표: 보스타이머

가장 먼저 보스타이머를 완성합니다.

최종적으로는 단순한 카운트다운만 보여주는 것이 아니라 다음과 같은 기능을 목표로 합니다.

- 회원과 그룹 관리
- 보스 등록
- 보스 처치 시간 기록
- 다음 출현 시간 자동 계산
- 여러 사용자의 실시간 상태 공유
- 알림
- 기록 조회
- 권한 관리
- 서버 재시작 후에도 타이머 복구
- 백업과 기본 보안
